웹에서 찾은 자료를 저장하고 보관함에서 다시 여는 방법을 안내합니다.

저장과 검색 다운로드 데이터 사용 안내 문의

저장한 웹페이지 다시 열기

웹페이지를 열고 브라우저 도구에서 인박스, 웹 북마크 또는 오프라인 사본 중 하나를 고르세요. 인터넷 연결 없이 읽으려면 오프라인 사본을 저장하세요.

보관함 검색은 저장한 자료 전체를 찾습니다. 웹 북마크나 자동 보관 안의 목록 검색은 현재 목록에서 찾습니다.

다운로드 상태 확인하기

브라우저 또는 파일 보관함에서 다운로드 내역을 열면 진행 중, 완료, 실패 상태를 확인할 수 있습니다. 실패 항목에서 다시 시도하거나 원본이 남아 있으면 원본으로 돌아갈 수 있습니다.

데이터 사용 안내

이 기기에 저장되는 데이터

방문 기록, 웹 로그인 상태, 오프라인 사본과 내려받은 파일은 앱이 이 기기에서 관리합니다. 웹사이트를 열거나 파일을 받으면 해당 사이트와 통신합니다.

선택하는 iCloud 동기화

보관함 동기화는 설정에서 켭니다. Apple 계정의 iCloud에 북마크, 인박스, 모음과 재생 기록 등의 보관함 정보가 저장됩니다. 다운로드 목록 공유를 켜면 일반 다운로드의 제목, 태그와 다시 받을 때 필요한 출처도 기기 간에 이어집니다. 저장한 파일, 오프라인 사본, 비공개 다운로드와 웹 로그인은 이 동기화에 포함되지 않습니다.

기기 안에서 처리하는 기능

지원 기기에서 사용 가능한 인박스 분석은 Apple의 기기 내 언어 모델을 사용합니다. 웹페이지 번역은 Apple의 번역 기능을 사용합니다.

직접 공유하는 진단

문제가 생겼을 때 앱에서 진단 내용을 먼저 확인한 뒤 공유할 수 있습니다. 지원 문의를 보내면 문의 내용과 회신 주소가 전달됩니다.
