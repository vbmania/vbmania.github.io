이 문서는 2026년 9월 개편 기능을 설명해요. 앱 업데이트 적용 시점에 따라 이전 버전의 화면과 일부 기능이 다를 수 있어요.

현행 기능 안내 갱신일: 2026년 9월 10일

내 은퇴 계획은 입력한 자산·소득·연금·생활비·부채와 계산 결과를 운영자 서버로 보내지 않습니다. 계획은 토스 미니앱의 기기 저장소에만 보관합니다.

1. 처리하는 정보와 목적

  • 사용자가 입력한 나이, 은퇴 시점, 자산, 소득, 연금, 생활비, 부채, 주거 및 투자 가정은 은퇴 시뮬레이션과 저장된 계획 복원에만 사용합니다.
  • 예외상황 실험은 사용자가 저장을 선택한 경우에만 당시 계획, 선택한 상황·금액·기간, 비교 결과와 재현용 번호를 기기에 최대 10개 보관합니다. 가족 돌봄·의료비와 더 긴 계획 기간은 직접 선택했을 때만 계산합니다. 비용 가정만 사용하며 실제 진단명·병력·가족 신원은 요청하지 않습니다.
  • PDF 보고서는 금융 입력값과 계산 결과를 포함하며 기기 안에서 만듭니다. 사용자가 파일 저장·열기를 선택하면 토스 플랫폼의 파일 기능으로 전달합니다. 별도의 ‘내 금액 없이 앱 소개하기’는 정해진 소개 문구와 앱 링크만 공유 기능으로 전달하며 개인 금액이나 계산 결과를 넣지 않습니다. 공유 대상과 전송 여부는 사용자가 정합니다.
  • 현재 버전에서는 나이를 직접 입력하며 생년월일·성별 제공을 요청하지 않습니다. 이전 버전에서 저장한 나이와 정규화한 계획 기준은 기존 계획을 복원할 때 사용합니다. 원본 생년월일과 원본 성별 값은 저장하지 않습니다.
  • 보상형 광고나 이전 혜택으로 얻은 분석 이용 권한은 분석 종류, 취득 이유와 시각을 현재 기기에 보관해요. 일반 전면광고를 사용하는 버전에서는 같은 이용 중 열어본 분석 종류를 세션 저장소에 기록하고, 광고 간격을 지키기 위해 마지막으로 광고가 실제 표시된 시각을 기기에 기록해요. 해당 저장소를 사용할 수 없으면 이번 실행의 메모리에서만 관리해요. 금융정보를 지워도 이 분석 이용 기록은 유지돼요.
  • 현재 버전은 새 친구 초대·SNS 공유 혜택을 제공하지 않습니다. 이전 버전의 SNS 공유 혜택 서버에는 앱 전용 익명 식별값을 가명 처리한 값, 무작위 공유 임시번호, 생성·확인 시각과 혜택 상태가 남아 있을 수 있습니다. 이름, 연락처, 토스 계정 정보, 금융 입력값과 계산 결과는 이 서버에 전송하지 않습니다.

2. 분석과 광고

첫 계획 완성 프로모션을 제공하는 버전에서는 중복 지급 요청을 막기 위해 요청 중·성공·실패 상태를 기기의 앱 전용 저장소에 보관합니다. 포인트 지급은 토스가 처리하며, 앱은 프로모션 코드와 지급 금액만 공식 SDK에 전달합니다. 이 요청에 금융 입력값이나 계산 결과를 넣지 않으며, 지급 응답의 고유번호도 저장하지 않습니다. 프로모션 진행 여부와 지급 조건은 토스의 해당 프로모션 안내를 따릅니다.

서비스 개선을 위해 화면 유입, 시작, 단계 완료, 결과·분석 열림, 오류 사유, 광고 요청·표시·실패 같은 정해진 종류의 이벤트를 기록할 수 있어요. 앱이 직접 추가하는 이벤트 정보에는 나이, 성별, 입력 금액, 계산 결과, 사용자·기기 식별자, 원문 오류와 URL을 넣지 않아요. 토스의 공식 SDK는 이용 현황을 집계하기 위한 플랫폼 가명키를 자동으로 포함해요. 앱은 이 키를 생성하거나 별도로 저장하지 않아요.

일부 상세 분석에는 토스 미니앱에서 제공하는 광고가 나올 수 있어요. 일반 전면광고를 사용하는 버전에서는 같은 이용 중 열어본 분석을 추가 광고 없이 다시 볼 수 있고, 실제 광고 표시 후 최소 5분 동안 다른 분석에도 광고를 표시하지 않아요. 새 이용에서는 광고가 다시 나올 수 있어요. 보상형 광고를 안내하는 이전 버전에서 얻은 분석 이용 권한은 유지돼요. 광고 종류와 이용 조건은 사용 중인 버전의 안내에서 확인할 수 있어요.

3. 저장 기간과 삭제

PDF 미리보기와 앱 소개 공유는 무료입니다. PDF 파일 받기는 지원하는 토스 앱에서 보상형 광고 시청 후 이용할 수 있으며, 같은 실행 중 다시 저장하는 데에는 추가 광고를 요구하지 않습니다. 광고 로드·표시 장애 때에는 광고 없이 저장을 이어갑니다. 파일 저장을 지원하지 않는 환경에서는 미리보기만 제공하고 광고를 표시하지 않습니다.

금융 입력·직전 계획·저장한 예외상황 실험은 앱의 ‘입력한 내용 → 기기에 저장된 계획 삭제 → 입력한 금융정보 삭제’에서 지울 수 있습니다. 실험은 저장 목록에서 개별 삭제할 수도 있습니다. 이 동작은 열어둔 분석의 이용 기록이나 이전 공유 혜택 서버 기록을 삭제하지 않습니다. 직접 저장하거나 다른 사람에게 전달한 PDF도 삭제되지 않으므로 파일 보관 위치에서 별도로 관리해 주세요. 앱 재설치나 기기 변경 시 기기 저장 내용은 유지되지 않을 수 있습니다.

이전 SNS 공유 임시번호와 중복 참여 방지 기록에는 30일 만료·삭제 기준을 적용합니다. 서버에 적용된 무료 이용 상태는 이 자동 삭제 대상에 포함되지 않습니다. 현재 버전에는 서버 공유 기록을 직접 지우는 버튼이 없으므로, 이전 공유 기록이나 분석 이용 기록의 삭제가 필요하면 아래 개인정보 문의로 알려주세요. 문의에 금융 금액·비밀번호·계좌번호를 보내지 마세요.

프로모션 요청 상태는 중복 요청 방지를 위해 금융정보를 삭제해도 유지합니다. 앱 전용 저장소가 초기화되면 이 기록도 사라질 수 있으며, 토스가 보관하는 실제 포인트 지급 내역과는 별개입니다. 기기 기록의 삭제에 도움이 필요하면 아래 개인정보 문의로 알려주세요.

운영자는 입력한 금융 정보와 계산 결과를 별도 서버에 수집하거나 판매하지 않습니다. 이전 SNS 공유 혜택 확인 서버는 Cloudflare Workers와 D1을 이용하며 위에서 밝힌 가명 식별값·임시번호·처리 시각·혜택 상태를 보관합니다. 광고·분석 기능은 토스 미니앱 플랫폼의 계약과 정책에 따라 동작하며, 해당 기능에 개인 재무 입력값을 전달하지 않습니다.
