내 음식 취향표

개인정보처리방침

시행일 2026년 10월 7일 · 에이아이워커스랩

1. 운영자와 적용 범위

에이아이워커스랩은 앱인토스에서 ‘내 음식 취향표’를 제공합니다. 이 방침은 음식 비교·순위·취향 요약·공유·이어하기 기능에서 앱이 처리하는 정보와 문의 창구를 안내합니다. 앱에 별도 회원가입·토스 로그인·결제·운영자 서버 동기화 기능은 없습니다.

2. 기기에 저장하는 정보

음식 비교 선택, 동률, 제외한 음식, 비교 순서, 전체 순위 이어하기 상태를 현재 기기에 저장합니다. 토스에서는 앱인토스 Storage를 사용하고 브라우저 미리보기에서는 localStorage를 사용합니다. 운영자 서버로 음식 선택 기록을 전송하지 않습니다. 리뷰 요청을 자주 표시하지 않도록 마지막 요청 시각을 기기에 저장할 수 있습니다.

기기의 취향 기록은 이용자가 앱의 ‘내 기록 지우기’를 실행하거나 해당 앱의 저장 공간을 삭제할 때까지 보관합니다. 기기 변경·재설치·저장 공간 삭제 시 복원하지 못할 수 있습니다.

3. 이용 흐름 측정과 광고

앱 개선을 위해 진입·일정 시간 이용·비교 시작·비교 횟수 구간·완료·동률/제외/되돌리기 사용·이어하기·결과 보기·공유·오류 발생·리뷰 열기 이벤트와 알고리즘 버전을 앱인토스 Analytics SDK로 전달합니다. 음식 이름·음식 ID·선택한 쪽·제외 이유·실명·연락처·토스 userKey를 이 이벤트에 넣지 않습니다. TEST와 운영 이벤트 이름을 구분하고 세션 단계와 횟수 구간의 중복을 줄입니다.

다른 앱 소개의 노출·열기·도착·첫 행동·완료는 소개 출처/대상 앱·표시 위치·문구 버전·무작위 클릭 ID로 측정할 수 있습니다. 여기에 음식 선택값이나 사용자 식별자를 넣지 않습니다. 소개 목록은 공개된 정적 파일을 읽고 기기에 캐시합니다.

앱인토스 SDK는 페이지 이동 로그를 자동으로 기록할 수 있습니다. 분석 데이터는 실제 출시 후부터 집계됩니다. 자세한 플랫폼 로깅 방식은 앱인토스 로그 가이드에서 확인할 수 있습니다.

화면 아래 광고는 앱인토스 광고 SDK로 제공할 수 있습니다. 광고가 없거나 불러오지 못해도 음식 비교와 결과를 이용할 수 있습니다. 토스 플랫폼이 분석·광고·서비스 제공 과정에서 처리하는 정보와 보관·권리 행사 절차는 토스 개인정보처리방침을 확인해 주세요. 앱의 취향 기록 삭제는 플랫폼의 이용·분석·광고 기록 삭제를 뜻하지 않습니다.

4. 공유와 외부 페이지

이용자가 공유를 누르면 현재 순위 문구와 앱 링크를 토스 공유 기능, 기기의 공유 기능 또는 복사 기능에 전달합니다. 공유 대상과 수단은 이용자가 선택합니다. 제외 이유나 개인 식별 정보는 공유 문구에 넣지 않습니다. 공유 상대가 받은 내용은 앱에서 지울 수 없습니다.

이 법률 페이지와 공개 앱 소개 파일은 GitHub Pages에서 제공합니다. 페이지·파일 방문 과정의 접속 정보 처리는 GitHub 개인정보처리방침을 확인해 주세요. 이 법률 페이지에는 입력 폼·분석 스크립트·광고가 없습니다.

5. 문의 정보와 권리 행사

문의 시 이용자가 보내는 이메일 주소와 문의 내용은 답변·문제 해결 및 개인정보 권리 요청 처리에 사용합니다. 문의 처리 목적이 달성되면 삭제하며 법령상 보관이 필요한 경우에는 해당 의무 기간 동안 보관합니다. 문의에 비밀번호·인증번호·민감정보를 보내지 마세요.

개인정보 열람·정정·삭제·처리 정지 및 서비스 문의는 에이아이워커스랩 고객지원 contact.aiworkerslab@gmail.com에서 받습니다. 문의 제목에 ‘내 음식 취향표’를 적어 주세요. 기기의 음식 선택 기록은 앱에서 직접 삭제할 수 있습니다.

6. 방침 변경

기능이나 정보 처리 방식이 바뀌면 이 페이지와 앱 안내를 갱신합니다. 이용자의 권리에 영향을 주는 변경은 적용 전에 안내합니다.
